System](https://dsf.berkeley.edu/papers/fntdb07-architecture.pdf)을 읽고 생각나는 대로 메모를

관계형 질의 처리기(Relational Query Processor, RQP)는 선언적인 SQL문을 받아서, 유효성을 확인하고,
절차적인 데이터 흐름 실행 계획으로 최적화하고, 그 데이터 흐름의 실행 계획을 클라이언트 프로그램 대신
실행한다.
